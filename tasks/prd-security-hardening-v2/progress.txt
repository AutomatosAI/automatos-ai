## Codebase Patterns
- Auth dependency: `get_request_context_hybrid` from `core.auth.hybrid` — returns `RequestContext` with `.user`, `.workspace_id`, `.auth_type`
- Admin check pattern: `ctx.user.system_role == "admin"` or `ctx.auth_type == "api_key"` for service-to-service
- Router imports: `from core.auth.hybrid import get_request_context_hybrid` + `from core.auth.dependencies import RequestContext`
- Error handling: `raise HTTPException(status_code=..., detail=...)` — should use generic messages, log details server-side
- Existing error utility: `core/utils/error_handling.py` has `raise_safe_error()` already
- File structure: routers in `orchestrator/api/`, core in `orchestrator/core/`, modules in `orchestrator/modules/`
- Docker pattern: non-root `automatos` user (UID 1000) with `chown -R automatos:automatos /app`
- Audit logging: dedicated `audit` logger name, JSON-formatted structured records
