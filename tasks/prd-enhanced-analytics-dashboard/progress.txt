## Codebase Patterns
- LLM services live in `orchestrator/core/llm/` — standalone classes, no base class needed for analytics services
- Use `httpx.AsyncClient` for async HTTP calls (preferred pattern), `requests` for sync
- DB session via `from core.database.database import SessionLocal` — create, use, close manually
- `LLMUsage` model in `core/models/core.py` — fields: workspace_id, model_id, provider, tier, input_tokens, output_tokens, total_tokens, input_cost, output_cost, total_cost, is_byok, latency_ms, status, error_message, created_at
- `UserApiKey` model — encrypted_key decrypted via `get_encryption_service().decrypt()`
- OpenRouter headers: `Authorization: Bearer {key}`, `HTTP-Referer: https://automatos.app`, `X-Title: Automatos AI`
- No formal mypy/pyright setup — typecheck = `python -m py_compile` succeeding
- API routers in `orchestrator/api/` — FastAPI pattern with `RequestContext` + `get_request_context_hybrid`
- Resolve BYOK keys via `_resolve_openrouter_key` pattern: query `UserApiKey` (workspace + provider + is_active), decrypt, fallback to env var, 404 if missing
- llm_analytics.py router prefix: `/api/analytics/llm` — already registered in main.py
