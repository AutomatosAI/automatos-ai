## Codebase Patterns
- ORM models import Base from `core.database.base` (separate file to avoid circular imports)
- All ORM models use `extend_existing=True` in `__table_args__` for safety
- Enums use `(str, Enum)` pattern for automatic string serialization
- Pydantic and SQLAlchemy models co-exist in the same module file under `core/models/`
- Register new model modules in `core/models/__init__.py` with wildcard imports
- Timestamps use `func.now()` from `sqlalchemy.sql` for server-side defaults
- JSON/flexible columns use `JSONB` from `sqlalchemy.dialects.postgresql`
- UUID columns use `PGUUID(as_uuid=True)` from `sqlalchemy.dialects.postgresql`
- Workspace isolation: most models include `workspace_id` FK to workspaces table
- Routing cache lives at `core/routing/cache.py` — use `RoutingCache` singleton for all routing cache operations
- Use `model_copy()` (Pydantic v2) when storing/returning models to avoid shared mutable state

## 2026-02-01 - US-002
- **What was implemented:** Built routing cache with TTL and workspace scoping in `orchestrator/core/routing/cache.py`
- **Features:**
  - `RoutingCache` class with in-memory dict store keyed by `(workspace_id, sha256(normalized_content + source))`
  - Configurable TTL via `ROUTING_CACHE_TTL_HOURS` env var (default 24 hours)
  - `get()` — returns cached RoutingDecision with `cached=True`, or None (with lazy eviction)
  - `put()` — stores decision with monotonic timestamp
  - `record_correction()` — tracks corrections per agent_id; auto-updates cached entry after 2+ identical corrections
  - `clear(workspace_id)` — removes all cache entries for a workspace
  - `stats()` — returns size, hits, misses, hit_rate, top_routes (top 10 by agent_id)
  - Content normalization: lowercase + strip whitespace for consistent hashing
