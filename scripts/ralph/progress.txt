## Codebase Patterns
- Models use `Base` from `core.database.base` (separate module to avoid circular imports)
- UUID PKs use `Column(PGUUID(as_uuid=True), primary_key=True, default=uuid4)` pattern (import `UUID as PGUUID` from `sqlalchemy.dialects.postgresql`)
- All models use `__table_args__ = {"extend_existing": True}` to prevent duplicate table errors
- Timestamps use `server_default=func.now()` for DB-side defaults
- ARRAY columns: `Column(ARRAY(String), default=list)` from `sqlalchemy`
- JSONB columns: `Column(JSONB, default=dict)` from `sqlalchemy.dialects.postgresql`
- Junction/association tables in core.py use `Table()` function with Integer FKs; newer models use `Column()` class approach
- Agent model uses Integer PK (id), Workspace uses UUID PK — FK references must match
- Users model uses Integer PK
- Model registration in `__init__.py` — import order matters for FK resolution
- Junction tables with composite PKs: set `primary_key=True` on each FK column, no separate `id` needed
- FK type must match target PK: Agent(Integer), Workspace(UUID), User(Integer), MarketplacePlugin(UUID)
- Config pattern: `Config` class in `orchestrator/config.py` with `os.getenv()` calls, singleton `config` instance
- Router registration in `main.py`: import router, `app.include_router(router)`, optional routers use try/except
- Frontend has no TypeScript compiler installed; `next.config.js` has `ignoreBuildErrors: true`
- Python has no type checker (mypy/pyright) configured; verify imports work as typecheck proxy
- AWS/boto3 pattern: use `try/except ImportError` guard, `boto3.client()` with `BotoConfig` for retries, wrap sync calls with `asyncio.run_in_executor()` for async
- S3 service reads creds from config singleton — `config.AWS_ACCESS_KEY_ID`, `config.AWS_SECRET_ACCESS_KEY`, `config.AWS_REGION`, `config.MARKETPLACE_S3_BUCKET`
- boto3 not installed locally; service guards with try/except and raises ImportError at instantiation time
- Pydantic v2 `model_` prefix is reserved; fields like `model_used` need `model_config = {"protected_namespaces": ()}` on the BaseModel class
- LLM JSON responses may have markdown code fences — strip before `json.loads()`
- Admin auth: `_assert_admin(ctx)` checks `ctx.user.system_role == 'admin'`, raises 403
- API auth dependency: `ctx: RequestContext = Depends(get_request_context_hybrid)` from `core.auth.hybrid`
- DB session dependency: `db: Session = Depends(get_db)` from `core.database.database`
- UploadFile multipart: `file: UploadFile = File(...)`, non-file fields use `Form()` not `Query()`
- Import services inside endpoint functions to avoid circular import at module load time
- FastAPI route ordering: fixed-path routes (e.g., `/categories`) must be defined before parameterized routes (e.g., `/{plugin_id}`) in the same router
- ARRAY contains-element filter: `Model.array_col.any(value)` for PostgreSQL ARRAY columns
